Arduino দিয়ে প্রথম প্রজেক্ট: LED Blink থেকে IoT পর্যন্ত

Arduino শেখার শুরুটা সবার জন্যই একটু ভয়ের মনে হয়। কিন্তু সত্যি বলতে, এটা এতটাই সহজ যে একবার শুরু করলে আর থামা যায় না! আমার Arduino যাত্রা শুরু হয়েছিল একটা ছোট্ট LED জ্বালানো থেকে, আর এখন আমি পুরো IoT সিস্টেম বানাচ্ছি।

Arduino কী এবং কেন শিখবেন?

Arduino হলো একটি open-source electronics platform যেখানে hardware আর software একসাথে কাজ করে। এটা শিখলে আপনি real world এর physical objects কে control করতে পারবেন — যেমন motor চালানো, sensor থেকে data পড়া, বা internet এর সাথে সংযুক্ত করা।

💡 কেন Arduino শিখবেন?
  • EEE students দের জন্য perfect starting point
  • Relatively সস্তা এবং সহজলভ্য
  • বিশাল community এবং tutorial আছে
  • Job market এ IoT skill এর চাহিদা বাড়ছে

প্রথম প্রজেক্ট: LED Blink

সবচেয়ে বিখ্যাত Arduino প্রজেক্ট হলো LED blink। মাত্র কয়েক লাইন কোড দিয়ে আপনি একটা LED জ্বালাতে এবং নেভাতে পারবেন:

// LED Blink - প্রথম Arduino প্রজেক্ট
void setup() {
  pinMode(13, OUTPUT);  // Pin 13 কে output হিসেবে সেট করুন
}

void loop() {
  digitalWrite(13, HIGH);  // LED জ্বালান
  delay(1000);              // ১ সেকেন্ড অপেক্ষা করুন
  digitalWrite(13, LOW);   // LED নেভান
  delay(1000);              // আবার ১ সেকেন্ড
}

মাত্র ৮ লাইন কোড! কিন্তু এই ছোট্ট কোডটিই আপনাকে শেখাবে কীভাবে Arduino এ pin control করতে হয়।

পরবর্তী ধাপ: Sensor ব্যবহার

LED blink শেখার পর আমি DHT11 temperature sensor ব্যবহার করতে শিখলাম। এই sensor দিয়ে তাপমাত্রা এবং আর্দ্রতা মাপা যায়:

#include <DHT.h>

#define DHTPIN 2
#define DHTTYPE DHT11

DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  float temp = dht.readTemperature();
  float humid = dht.readHumidity();
  
  Serial.print("Temperature: ");
  Serial.print(temp);
  Serial.println("°C");
  
  Serial.print("Humidity: ");
  Serial.print(humid);
  Serial.println("%");
  
  delay(2000);
}

IoT পর্যন্ত যাত্রা

Arduino এর সাথে ESP8266 WiFi module যোগ করলে আপনি internet connected devices বানাতে পারবেন। আমার সবচেয়ে ভালো প্রজেক্ট ছিল একটা smart temperature monitor যেটা data cloud এ পাঠাত এবং phone এ notification আসত।

প্রয়োজনীয় উপকরণ

  • Arduino Uno বোর্ড (~৫০০-৮০০ টাকা)
  • Breadboard এবং jumper wires
  • LED, resistor (220Ω)
  • DHT11 sensor (optional)
  • ESP8266 module (IoT এর জন্য)
"Hardware programming কঠিন মনে হলেও, Arduino দিয়ে শুরু করলে অনেক সহজ হয়ে যায়। প্রতিটি ছোট সাফল্যই আপনাকে এগিয়ে নিয়ে যাবে।"

উপসংহার
