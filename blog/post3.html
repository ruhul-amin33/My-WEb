CSS Glassmorphism: আধুনিক UI ডিজাইনের নতুন ট্রেন্ড

👨‍💻

🌐

Glassmorphism হলো একটি UI design trend যেখানে frosted glass এর মতো effect তৈরি করা হয়। এই effect এখন সব জায়গায় দেখা যাচ্ছে — Apple এর macOS, Windows 11, এমনকি বড় বড় web apps এ। CSS দিয়ে এই চমৎকার effect তৈরি করা একদমই সহজ!

Glassmorphism Effect এর মূল উপাদান

Glassmorphism তৈরি করতে মূলত ৩টি CSS property ব্যবহার হয়: backdrop-filter, background transparency, এবং subtle border। একসাথে এগুলো frosted glass এর মতো appearance দেয়।

.glass-card {
  background: rgba(255, 255, 255, 0.2);
  backdrop-filter: blur(20px);
  -webkit-backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.3);
  border-radius: 20px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.1);
}

Dark Mode এ Glassmorphism

Dark theme এ glassmorphism আরও সুন্দর দেখায়। Background অন্ধকার রেখে glass card এ slight transparency দিলে একটা premium look আসে। CSS variables ব্যবহার করলে light/dark mode switch করা অনেক সহজ হয়।

প্রতিটি নতুন জিনিস শেখার সময় ভয় লাগবেই — কিন্তু শেখার পর সেই আনন্দই হলো সবচেয়ে বড় পুরস্কার।
