C Programming এ Pointer: ভয় নয়, জয়!

C programming এ pointer নিয়ে সবার একটু ভয় থাকে। কিন্তু pointer বুঝলে C programming এর অনেক কিছুই পরিষ্কার হয়ে যায়। আজকে সহজ বাংলায় pointer এর concept, declaration, এবং ব্যবহার দেখব।

Pointer কী?

Pointer হলো এমন একটি variable যেটা অন্য একটি variable এর memory address store করে। সহজ কথায়, pointer একটি address hold করে। যেমন আপনার বাড়ির ঠিকানা জানলে আপনি সেই বাড়িতে যেতে পারবেন — pointer ও ঠিক এভাবে কাজ করে।

#include 

int main() {
    int num = 42;        // একটি integer variable
    int *ptr = #     // pointer যেটা num এর address রাখে
    
    printf("Value: %d\n", num);        // 42
    printf("Address: %p\n", &num);     // memory address
    printf("Via pointer: %d\n", *ptr); // 42 (dereference)
    
    *ptr = 100;  // pointer দিয়ে value পরিবর্তন
    printf("New value: %d\n", num);    // 100
    
    return 0;
}

Pointer এর practical ব্যবহার

Pointer এর সবচেয়ে গুরুত্বপূর্ণ ব্যবহার হলো function parameter pass করা (call by reference), dynamic memory allocation, এবং array manipulation। এই জিনিসগুলো pointer ছাড়া করা সম্ভব নয়।

প্রতিটি নতুন জিনিস শেখার সময় ভয় লাগবেই — কিন্তু শেখার পর সেই আনন্দই হলো সবচেয়ে বড় পুরস্কার।
